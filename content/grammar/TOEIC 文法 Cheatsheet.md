# TOEIC 文法 Cheatsheet

藍本 GRAMMAR 20 章的一頁速查。每章只留「看到什麼線索、選什麼」，細節、注意事項、例題點進章節。

## 0. Part 5 三步解題法（每題 20 秒）
1. **看選項**：同字不同詞性（考詞性，第 10～13 章）、同動詞不同形式（考時態／語態／一致，第 03～06 章）、四個不同的字（考字義與搭配，詞彙章）、連接詞與介系詞混雜（第 14、15、17 章）。
2. **看空格前後 3 到 5 個字**：判斷缺的是主詞、動詞、受詞、補語還是修飾語（第 01、02 章）。
3. **找線索詞**：時間副詞決定時態；be 後面有無受詞決定語態；逗號與連接詞決定子句結構。

## Section 1 句型
### 01 主詞、動詞 → [[文法01 主詞、動詞]]
- 每個句子只有一個主要動詞；空格前是完整主詞且句中沒有動詞 → 選**動詞**。
- 主詞位置只能放名詞、代名詞、動名詞、to 不定詞、名詞子句；不能放形容詞或動詞。
- 祈使句省略主詞，動詞用原形（Please **submit** the form）。
- 主詞後的介系詞片語、關係子句都不是動詞，劃掉再找。

### 02 受詞、補語、修飾語 → [[文法02 受詞、補語、修飾語]]
- 及物動詞後缺受詞 → 名詞；be／become／remain／seem 後 → 形容詞或名詞補語。
- 修飾語（形容詞、副詞、介系詞片語、分詞片語）拿掉句子仍完整；空格是修飾語時看修飾對象決定詞性。
- 五種句型：S+V／S+V+C／S+V+O／S+V+O+O／S+V+O+C。

## Section 2 動詞片語
### 03 動詞的形態與種類 → [[文法03 動詞的形態與種類]]
- 助動詞（will、can、must、should、may）後一律**原形**；have 後 p.p.；be 後 V-ing 或 p.p.。
- 及物動詞直接接受詞（discuss、attend、contact、approach），不加介系詞；不及物動詞要接介系詞才能接受詞（respond **to**、participate **in**）。
- 建議／要求動詞（suggest、recommend、request、require、insist）+ that + S + **原形**。

### 04 動詞與主詞的單複數一致 → [[文法04 動詞與主詞的單複數一致]]
- 劃掉主詞後的修飾語再看單複數：The manager ~~of the branches~~ **is**…
- each／every／everyone 單數；a number of + 複數動詞；the number of + 單數動詞。
- either…or／neither…nor 看最近的主詞；動名詞、to 不定詞、名詞子句當主詞算單數。
- some／most／all／half of + 名詞 → 看名詞。

### 05 主動態與被動態 → [[文法05 主動態與被動態]]
- 空格後**沒有受詞** → 被動 be + p.p.；有受詞 → 主動。
- 不及物動詞無被動：arrive、occur、happen、remain、rise、exist、take place。
- 被動 + 介系詞固定搭配：be located in、be equipped with、be committed to、be required to、be known for、be involved in。
- 授與動詞被動後仍可接一個名詞：He **was awarded** a bonus。

### 06 時態與假設語氣 → [[文法06 時態與假設語氣]]
| 線索詞 | 時態 |
|---|---|
| yesterday、ago、last、in 2019 | 過去簡單 |
| since、for + 期間、already、yet、so far、over the past、recently | 現在完成 |
| by the time + 過去式 | 過去完成 had p.p. |
| by next month、by the time + 現在式 | 未來完成 will have p.p. |
| currently、now、at the moment、presently | 現在進行 |
| every、usually、regularly、often | 現在簡單 |
| next、tomorrow、soon、shortly、upcoming | 未來 |
- when／as soon as／once／until／before／after／if 引導的子句用**現在式代替未來**。
- 假設：與現在相反 If + 過去式, would + V；與過去相反 If + had p.p., would have p.p.；倒裝 **Should** you…／**Had** we…／**Were** it not for…。
- should have p.p.（該做未做）、must have p.p.（過去推論）。

## Section 3 動狀詞
### 07 to 不定詞 → [[文法07 to 不定詞]]
- 只接 to V：want、plan、decide、hope、expect、agree、refuse、promise、offer、fail、afford、manage、intend、tend、hesitate、would like。
- 名詞後接 to V：ability、decision、effort、plan、opportunity、right、way、attempt、willingness。
- 形容詞後接 to V：able、likely、eligible、ready、willing、pleased、reluctant、scheduled、due。
- 表目的：to V、in order to、so as to；enable／allow／require／expect／ask + O + to V。

### 08 動名詞 → [[文法08 動名詞]]
- 只接 V-ing：enjoy、avoid、consider、suggest、recommend、finish、mind、postpone、delay、keep、practice、admit、deny、discontinue、risk、appreciate。
- 介系詞後一律 V-ing：look forward to、be used／accustomed to、object to、be committed to、contribute to、in addition to、instead of、by、upon。
- 動名詞可直接接受詞（**reviewing** the contract）；-tion 名詞要加 of（the **review** of the contract）。
- stop／remember／forget + to V 與 V-ing 意思不同。

### 09 分詞 → [[文法09 分詞]]
- 名詞主動做動作 → V-ing（a **leading** firm、the **remaining** budget）；名詞被動 → p.p.（the **attached** file、**qualified** applicants）。
- 名詞後修飾：employees **attending** the seminar／the report **submitted** yesterday。
- 情緒動詞修飾人用 -ed（interested、satisfied），修飾事物用 -ing。
- 分詞構句主詞須與主句一致：**Having** reviewed the proposal, the committee approved it。

## Section 4 詞性
### 10 名詞 → [[文法10 名詞]]
- 位置：冠詞／所有格／形容詞後、及物動詞後、介系詞後。
- 字尾：-tion／-sion、-ment、-ness、-ity、-ance／-ence、-ship、-al、-er／-or／-ee。
- 人／事物名詞成對：applicant／application、attendant／attendance、supervisor／supervision。
- 不可數：equipment、information、furniture、advice、luggage、machinery、merchandise、research、access、feedback。
- 複合名詞：safety **regulations**、sales **figures**、customer **satisfaction**。

### 11 代名詞 → [[文法11 代名詞]]
- 動詞前 → 主格；動詞或介系詞後 → 受格；名詞前 → 所有格；不接名詞且指「某人的東西」 → 所有代名詞（mine、theirs）。
- 反身：主詞受詞同一人、強調、by oneself。
- another + 單數；other + 複數；the other + 單／複數名詞（其餘的，= the others）；others／the others 不接名詞；each other = one another，只能當受詞。
- those who（那些人）；those／that of 代替前面名詞做比較；its 是所有格、it is 的縮寫是另一個字。

### 12 形容詞 → [[文法12 形容詞]]
- 位置：冠詞／所有格 + ___ + 名詞；be／become／remain／seem + ___。
- 字尾：-ive、-ous、-ful、-less、-able／-ible、-al、-ic、-ent／-ant；-ly 形容詞：timely、costly、friendly、likely。
- 數量形容詞：many／few／several／a number of + 複數；much／little／a great deal of + 不可數；each／every／another + 單數；all／both + 複數。
- 形近字：considerable（相當多的）／considerate（體貼的）；successful／successive；economic／economical；confident／confidential。

### 13 副詞 → [[文法13 副詞]]
- 位置：be + ___ + p.p.；have + ___ + p.p.；助動詞 + ___ + V；修飾形容詞、另一副詞、整句；句首逗號前。
- 常考：still、yet、already、even、only、also、very／much、well、hard／hardly、late／lately、high／highly、near／nearly、close／closely、most／mostly。
- 頻率副詞在一般動詞前、be 動詞後；almost 不能直接修飾名詞（almost **all** employees）。
- 連接副詞（however、therefore、moreover）不能連接兩個子句，前面要分號或句號。

### 14 介系詞 → [[文法14 介系詞]]
- on／upon + 動作名詞（arrival、receipt、completion、approval、departure）＝「一…就」＝ as soon as + 子句：**upon your departure from the hotel**；upon 更正式，但不接日期與地點。
- on time（準時）／in time（及時）；on request、on behalf of、on schedule、on a first-come, first-served basis。
- 介系詞 + N／代名詞／V-ing；連接詞 + S + V。because of／due to／owing to｜because／since／as；despite／in spite of｜although／though；during｜while。
- 雙棲單字 before、after、until、since、as：介系詞連接詞都能當，看後面接名詞還是 S + V。
| 用途 | 介系詞 |
|---|---|
| 時刻／日期／月年 | at 3 p.m.、on Monday、in March |
| 期限前 vs 持續到 | **by** Friday（完成）、**until** Friday（持續） |
| 時間長度 vs 起點 | **for** two weeks、**since** 2020 |
| 期間 vs 期限內 | **during** the meeting、**within** 30 days |
| 兩者 vs 三者以上 | between、among |
- 片語：despite／in spite of + N；because of／due to／owing to + N；regarding／concerning；in accordance with；in addition to；instead of；as of（自…起）；upon（一…就）；prior to；following。
- 介系詞後接名詞或 V-ing，不接子句。

## Section 5 連接詞與子句
### 15 對等連接詞與相關連接詞 → [[文法15 對等連接詞與相關連接詞]]
- and 是對等連接詞（A and B 當主詞→複數）；as well as／along with／together with 是片語介系詞，動詞看前面的 A（The manager, as well as the staff, **is**…）。
- as well as 後接 N／V-ing，兩邊平行；重心在 A（not only A but also B 重心在 B）；as well as 也可能是「和…一樣好」的原級比較。
- 對等：and、but、or、so、yet、for、nor，連接對等的字、片語、子句。
- 相關連接詞須**平行**：both A and B、either A or B、neither A nor B、not only A but also B、whether A or B。
- not only 放句首要倒裝：Not only **did** sales increase, but…

### 16 關係子句 → [[文法16 關係子句]]
- 關係詞後**缺主詞** → who／which／that；**缺受詞** → whom／which／that（可省略）；**完整句** → where／when；**所有格 + 名詞** → whose + N。
- 逗號後不用 that；介系詞後只能 which／whom；what 自帶先行詞不修飾名詞。
- 縮減：主動 → V-ing，被動 → p.p.；關係子句內動詞與先行詞一致。

### 17 副詞子句 → [[文法17 副詞子句]]
- 一秒判詞性（看空格右邊）：子句 → 從屬連接詞；名詞／V-ing → 介系詞；緊接逗號（空格, S + V）→ 連接副詞。
| 邏輯 | 從屬連接詞（+ 子句） | 介系詞（+ 名詞） | 連接副詞（獨立句） |
|---|---|---|---|
| 因果 | because、since、as、now that | because of、due to | therefore、consequently |
| 讓步 | although、though、even though、while | despite、in spite of | however、nevertheless |
| 條件 | if、unless、provided that、as long as、in case | in case of、in the event of | otherwise |
| 時間 | when、while、once、as soon as、until | during、upon、prior to | meanwhile、then、afterward |
- 判斷第一步：空格後是**子句**選連接詞、是**名詞**選介系詞、是**獨立句且前有分號或句號**選連接副詞。
- 時間／條件子句用現在式代未來；so that + S + can（目的）；so … that（結果）。

### 18 名詞子句 → [[文法18 名詞子句]]
- that + 完整句（陳述）；whether／if + 完整句（是否）；疑問詞（what、who、which、when、where、how）+ 子句。
- what 後面是**不完整句**（缺主詞或受詞），that 後面是**完整句**。
- 名詞子句可當主詞、受詞、補語；當主詞時動詞用單數。
- whether 可接 or not、可放介系詞後；if 不行。

## Section 6 特殊句型
### 19 比較句型 → [[文法19 比較句型]]
- as + 原級 + as；比較級 + than；the + 最高級 + in／of／among。
- 選詞性看空格左邊：be／連綴動詞 + 形容詞比較級（is **more efficient**）；一般動詞 + 副詞比較級（works **more efficiently**）。
- 加強比較級：much、far、even、still、a lot、significantly（不用 very）。
- 加強最高級：the 前面放 by far、far and away、much、quite、easily、nearly、almost；the 後面放 very、single 與序數（the **very** best、the **second** largest）。
- 最高級是範圍性比較：句中有 of all／among／in + 組織／this year 等三者以上範圍才用最高級（有 than、of the two 用比較級）。
- 副詞最高級可省略 the（works **hardest** of all），後面不接名詞；a most + 形容詞 + N 的 most = very，不是最高級。
- superior／inferior／prior／senior + **to**；the + 比較級, the + 比較級；比較對象對等（than **those** of last year）。
- less + 不可數、fewer + 可數；as many／much + N + as。

### 20 對等、倒裝句型 → [[文法20 對等、倒裝句型]]
- 平行結構：and／or／but 與相關連接詞前後詞性一致（**efficient** and **affordable**；**to reduce** costs and **to improve** quality）。
- 否定副詞句首倒裝：Never／Rarely／Seldom／Not until／Only + 助動詞 + S + V。
- 條件句倒裝：Should you…、Had we…、Were it not for…。
- Attached／Enclosed + be + S；so／neither／nor + 助動詞 + S（也是／也不）。
