## Part 5 詞彙題三步解題法（每題 15 秒）

1. **先看空格後面有沒有介系詞**。有的話，題目考的是搭配不是字義——直接從介系詞反推動詞或形容詞，句意都不用讀完。
2. **四個選項字義相近時，看「後面接什麼」**：接人還是接事、及物還是不及物、接 that 子句還是名詞。中文翻譯完全幫不上忙。
3. **四個選項拼字相近時，看修飾對象**：修飾人還是事物、數量還是態度。

## 搭配（第 05～09 章）

### 動詞 + 介系詞
接了介系詞就不能選及物動詞，這是最快的刪去法。

| 介系詞 | 動詞 |
|---|---|
| **with** | comply、collaborate、coordinate、cooperate、interfere、cope |
| **to** | adhere、object、contribute、refer、respond、subscribe、conform、resort |
| **in** | participate、specialize、result、engage、invest、succeed |
| **for** | apply、account、compensate、search、substitute、qualify |
| **on** | rely、depend、focus、concentrate、insist、elaborate |
| **from** | benefit、result、refrain、differ、suffer |
| **by** | abide |

> [!warning] 同一個動詞換介系詞就換意思
> - agree **with** 人或意見／agree **to** 提議或條件／agree **on** 議題
> - result **in** 導致結果／result **from** 起因於（方向相反，看主詞是原因還是結果）
> - attribute A **to** B 歸因／contribute **to** B 促成（方向相反）
> - account for 佔比例（多益主要考這個）／解釋原因
> - refer **to** 參考／refer A **to** B 轉介
> - 「遵守」四兄弟介系詞全不同：comply **with**、adhere **to**、abide **by**、conform **to**

> [!warning] 及物動詞後面不加介系詞
> discuss、attend、contact、reach、access、enter、approach、mention、observe、follow 直接接受詞。選項同時出現這些字時，看空格後有沒有介系詞就能刪掉一半。
> 例外陷阱：attend 是及物（出席），attend **to** 是「處理、照料」，兩回事。

### 三段式動詞
動詞 + A + 介系詞 + B。空格給動詞、句中已出現介系詞時，直接靠介系詞反選。

| 模式 | 動詞 |
|---|---|
| A **with** B | provide、supply、present、equip、replace、compare、associate |
| A **of** B | inform、notify、remind、advise、accuse、convince |
| A **from** B | prevent、prohibit、discourage、keep、protect、distinguish |
| A **to** B | attribute、ascribe、dedicate、devote、introduce、refer、transfer、submit |
| A **as** B | regard、view、describe、classify、recognize |
| A **for** B | compensate、reimburse、blame、thank、exchange |

> [!warning] 三段式的三個陷阱
> - **被動後介系詞要留著**：Staff were **informed of** the change；A is **provided with** B。
> - **from 後面接 V-ing**，不接原形：prevent／prohibit／discourage／keep + O + from + **V-ing**。
> - **consider 不加 as**（consider him a leader），但 **regard 的 as 不能省**（regard him **as** a leader）。
> - provide A **with** B ＝ provide B **for** A，但不能寫 provide A B。

### 形容詞 + 介系詞

| 介系詞 | 形容詞 |
|---|---|
| **for** | eligible、responsible、suitable、famous、known、grateful、accountable |
| **of** | aware、capable、indicative、typical、full、short |
| **to** | comparable、adjacent、similar、subject、committed、dedicated、devoted、accustomed、entitled、opposed |
| **with** | consistent、familiar、compatible、satisfied、pleased、associated |
| **in** | proficient、involved、interested、engaged |
| **on** | dependent、based、keen |
| **about** | knowledgeable、concerned、enthusiastic |

> [!warning] 換介系詞就換意思的形容詞
> - be responsible **for** 負責某事／be responsible **to** 對某人負責
> - be eligible **for** + 名詞／be eligible **to** + 原形動詞
> - be available **to** 人／be available **for** 用途或時間
> - be familiar **with** 人熟悉事物／be familiar **to** 事物對人而言熟悉（主詞相反）
> - be concerned **about** 擔心／be concerned **with** 與…有關
> - be subject to 兩義：受制於（subject to approval）／可能發生（subject to change）
> - be capable **of** + V-ing vs be able **to** + 原形，介系詞不能互換

### 名詞 + 介系詞

| 介系詞 | 名詞 |
|---|---|
| **to** | access、response、solution、approach、alternative、objection、commitment |
| **for** | demand、request、need、reputation、responsibility、application |
| **in** | increase、decrease、rise、decline、change、interest、experience |
| **of** | approval、copy、lack、possibility、advantage |
| **on** | impact、effect、emphasis、restriction |
| **with** | compliance、experience、familiarity |

> [!warning] 名詞介系詞的四個陷阱
> - **access to** 的 access 是名詞；access 當動詞是及物，不加 to。
> - increase／decrease **in** 接變動項目、**of** 接數字幅度：an increase **in** sales **of** 10%。
> - in charge **of** 負責某事／in the charge **of** 在某人管理下。
> - reputation **for** + 特質／reputation **as** + 身分。

### 介系詞 + 名詞（副詞片語）
in advance、on schedule、on time（準時）／in time（及時，兩者不同）、on request、on behalf of、in accordance with、under warranty、out of stock、in compliance with、as of（自…起）、until further notice、on a first-come, first-served basis。

### 萬用動詞的固定搭配
選項四個都是「做」時，只能靠這張表。

| 動詞 | 常接的名詞 |
|---|---|
| **make** | a decision、a reservation、an appointment、progress、an effort、a payment |
| **take** | place（舉行）、effect（生效）、measures、advantage of、responsibility、a survey |
| **hold** | a meeting、a conference、a position、an event |
| **meet** | a deadline、requirements、demand、expectations、standards |
| **reach** | an agreement、a decision、a conclusion、a destination |
| **place** | an order、an advertisement、emphasis on |
| **conduct** | research、a survey、an interview、an inspection |
| **do** | research、business、a favor |

> [!warning] 搭配題最常錯的幾組
> - 做決定是 **make** a decision，不是 do／take；做研究是 **do／conduct** research，不用 make。
> - take place、take effect 都**不能用被動**（be taken place ✗）。
> - meet a deadline 趕上／miss 錯過／extend 延長。
> - 副詞 + 形容詞的固定組合：**highly** recommended／qualified、**readily** available（容易取得）、**widely** available（到處都有）、**by far the** + 最高級。

## 詞性與字義（第 01～04、10～12 章）

### 形近字
選項拼字相近時，看修飾的是人還是事物、數量還是態度。

| 組 | 差別 |
|---|---|
| considerable／considerate | 相當大的（修飾事物）／體貼的（修飾人） |
| economic／economical | 經濟的／省錢划算的 |
| successful／successive | 成功的／連續的 |
| respective／respectful／respectable | 各自的／有禮的／值得尊敬的 |
| confident／confidential | 有信心的／機密的 |
| complimentary／complementary | 免費招待的（多益考這個）／互補的 |
| industrial／industrious | 工業的／勤奮的 |
| later／latter／former | 之後／後者／前者 |
| affect／effect | 動詞「影響」／名詞「影響」 |
| rise／raise | 不及物（prices rose）／及物（raised prices） |
| lie／lay | 不及物／及物 |
| suit／suitable／suitably／suite | 動詞／形容詞／副詞／名詞（套房） |

> [!warning] 一字兩義，帳務情境選後者
> - **outstanding**：傑出的／**未付清的**（outstanding balance）
> - **receipt**：收據（可數）／**收到**（不可數，upon receipt of）
> - **policy**：政策／**保單**（insurance policy）
> - **notice**：通知（give notice 不可數）／公告（a notice 可數）
> - **address**（動詞）：**處理**、向…發言，不是「地址」
> - **decline**：婉拒（接 offer／invitation）／下滑（不接受詞）

### 人與事成對的名詞
看空格前的動詞：hire／contact／interview 後面要**人**，submit／review／process 後面要**事**。

applicant／application、attendant／attendance、supervisor／supervision、advisor／advice、participant／participation、accountant／accounting、employee／employer／employment。

### 不可數名詞
不加 a／an、不加 s、動詞用單數。選項出現 an equipment 直接刪。

equipment、information、merchandise、personnel、furniture、luggage、machinery、advice、feedback、access、research。

### 加 -ly 意思就變的副詞

| 原形 | 加 -ly |
|---|---|
| hard 努力地 | hardly 幾乎不 |
| late 晚 | lately 最近 |
| high 高 | highly 非常 |
| near 近 | nearly 幾乎 |
| close 近 | closely 仔細地 |
| most 最 | mostly 大多 |

### 副詞看修飾對象

| 修飾什麼 | 只能用 | 不能用 |
|---|---|---|
| 數字 | approximately、nearly、almost、roughly、about | very |
| 比較級 | much、far、even、still、considerably、significantly、slightly | very |
| 最高級 | by far、easily、quite、nearly | — |
| 整句（句首或逗號間） | unfortunately、accordingly、otherwise、however | — |

**時態線索**：currently／presently → 現在式或現在進行｜recently → 過去式或現在完成｜previously／formerly → 過去式｜lately → 現在完成｜shortly → 未來｜ago → 過去式｜since → 現在完成。

> [!warning] 位置固定的幾個副詞
> - still 在 be 後、一般動詞前；yet 在句尾且限否定與疑問；already 用於肯定。
> - respectively 一定放句尾，對應前面 A and B 的順序。
> - almost 不能直接修飾名詞（almost **all** employees）；approximately 只放數字前。
> - otherwise 三用法：句首連接副詞（否則）／unless otherwise noted／otherwise + 形容詞（在其他方面）。

### 近義詞的判斷準則
中文翻起來一樣時，靠這三件事分辨——

| 準則 | 例 |
|---|---|
| 接人還是接事 | inform／notify／remind + **人** + of；announce／explain／mention + **事**，對象用 to |
| 及物還是不及物 | raise 及物、rise 不及物；lay 及物、lie 不及物 |
| 後面能不能接 to V | reluctant／eager／willing／able／likely + **to V**；achieve／accomplish **不接** to V；suggest／recommend 不接「人 + to V」，要用 that + 原形 |

其他常考：gain experience（不用 obtain）｜fare 只用於交通票價、fee 用於服務與會員｜price 售價／cost 成本／value 價值｜client（律師、顧問業一定用）／customer｜expense（複數指開銷項目）／expenditure（總支出）｜postpone 不能當名詞，delay 可以（a two-hour delay）｜enclose 用於紙本、attach 用於電子郵件。

### 高頻片語動詞
整組當單字背，字面意思幫不上忙。

turn down 拒絕｜carry out 執行｜fill out 填寫｜call off 取消｜take over 接管｜take on 承擔、僱用｜turn in 繳交｜turn out 結果是｜set up 設立｜put off 延期｜look into 調查｜come up with 想出。

> [!warning] 受詞是代名詞時要放中間
> turn **it** down、fill **it** out、call **it** off——不能寫 turn down it。
