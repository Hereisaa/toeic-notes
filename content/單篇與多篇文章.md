# 單篇與多篇文章

> [!info] Part 7 是閱讀測驗分數占比最重的一大題：54 題裡單篇文章（Single Passage）約 29 題、雙篇文章（Double Passage）10 題、三篇文章（Triple Passage）15 題。本頁先建立題型與文章類型的骨架，之後刷題再依藍本實際章節切分補細節。

## 基礎觀念
Part 7 考的不是文法或單字本身，是「在有限時間內從文章裡精準定位答案」。所有題目都可以歸到七種題型之一，而文章可能是一篇（單篇）、兩篇（雙篇）或三篇（三篇）互相參照。多篇文章難的地方不在閱讀量，是找出「哪一題的答案要合併兩篇文章的資訊才能選」。

## 七種題型
| 題型 | 問句長相 | 解法 |
|---|---|---|
| 主旨題 | What is the purpose of...? / What is the article mainly about? | 看標題、開頭第一段、結尾，不用讀完全文 |
| 細節題 | What/When/Where/Who...? | 用問句關鍵字回文章找對應句，答案幾乎是原文改寫（同義詞替換） |
| 推論題 | What is suggested/implied about...? | 答案不會直接寫在文章裡，要從上下文合理推導，小心「過度推論」的陷阱選項 |
| NOT/TRUE 題 | What is NOT mentioned...? / What is true about...? | 逐一對照四個選項與文章，NOT 題用刪去法最快 |
| 詞彙同義題 | The word "X" in paragraph 2, line 5, is closest in meaning to | 回原文看該字在句子裡的意思，不是查該字最常見的字義 |
| 句意目的題 | Why does the writer mention...? | 看該句前後文的邏輯功能（背景、原因、對比、範例） |
| 跨文參照題（僅多篇文章） | 題目沒指定在哪一篇 | 兩篇文章都要看過一輪才能作答，通常是最後幾題 |

## 單篇文章：常見八種文件類型
| 文件類型 | 辨識特徵 | 常考重點 |
|---|---|---|
| email／letter | 有 To/From/Subject 或稱謂與署名 | 寫信目的（第一段）、請求的動作（結尾） |
| memo | 公司內部，開頭 To/From/Date/Re | 政策異動、內部公告 |
| notice／announcement | 標題粗體，公告語氣 | 生效日期、適用對象 |
| advertisement | 強調賣點、價格、聯絡方式 | 促銷條件、資格限制 |
| article／報導 | 有作者或出處，敘述語氣 | 主旨、數據、引言歸屬 |
| text-message chain／online chat | 多人對話，含時間戳記 | 說話者意圖（Why does X write "..."?）、上下文語意 |
| form／schedule／表格 | 表格、清單形式，資訊分散 | 交叉比對數字與條件 |
| web page／FAQ | 有分頁籤或連結樣式 | 依主題分區找對應段落 |

## 雙篇、三篇文章：跨文參照技巧
1. 先看每篇文章各自的**主旨與來源**（誰寫的、給誰看、為什麼寫），這決定了每篇的立場與資訊範圍。
2. 單篇能回答的題目先做（細節題、詞彙題），只有真正需要合併資訊的題目才需要來回翻頁。
3. 常見跨文考法：第一篇提到「規則／條件」，第二篇提到「某人的情況」，題目問這個人是否符合規則——答案要combine兩篇才能判斷。
4. 三篇文章通常第三篇是前兩篇之後新增的資訊（例如email回覆、後續更新），優先看第三篇會不會推翻或補充前兩篇的結論。

> [!warning] 注意
> - 選項字面上出現在文章裡不代表是答案；細節題的正解通常是**同義改寫**，字面完全相同反而常是陷阱選項。
> - NOT 題看到「all of the following EXCEPT」也是同一種解法，用刪去法。
> - 詞彙同義題一定要回文章讀該句，脫離上下文選最常見字義是最常見的失分點。

> [!tip] 多益出題方向
> 一篇文章的題目通常按文章順序出（第一題答案在文章前段，最後一題在後段），可以用這個規律加速定位；但主旨題、NOT 題例外，答案可能分散全文。
