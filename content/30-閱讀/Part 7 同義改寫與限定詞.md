# Part 7 同義改寫與限定詞

## 同義改寫不是字典的一對一替換

下列是**限定語境中的意思對照**。要核對主詞、時間、範圍；不能任意在所有句子互換。每日選 5 組遮住右欄回想。

| 原文可能寫                                  | 選項可能改寫成                                  | 要核對的條件     |
| -------------------------------------- | ---------------------------------------- | ---------- |
| The event has been put off.            | The event has been postponed.            | 延後，不是取消    |
| The item is out of stock.              | The item is currently unavailable.       | 因缺貨，不是停售   |
| There is no additional charge.         | The service is included in the price.    | 哪一項服務包含在內  |
| The fee will be waived.                | You will not have to pay the fee.        | 哪一筆費用      |
| Keep a copy for your records.          | Retain the document.                     | 保留哪份文件     |
| The store is being renovated.          | The premises are being remodeled.        | 文中是否指同一場所  |
| Please let us know by Friday.          | Respond no later than Friday.            | 截止日而非持續期間  |
| The offer applies to members only.     | Membership is required for the offer.    | 不能擴大到所有人   |
| We can fit forty guests.               | The venue can accommodate forty people.  | 不是預計出席人數   |
| The position has been filled.          | Someone has been hired for the role.     | 不是正在徵人     |
| The product did not meet expectations. | The customer was dissatisfied.           | 是否為該顧客的陳述  |
| We will send another unit.             | A replacement will be provided.          | 不是退款       |
| The timetable has been revised.        | The schedule has been changed.           | 哪些班次或日期改了  |
| Please check the figures.              | Verify the numbers.                      | 不是要求修改     |
| Staff must attend.                     | Attendance is mandatory.                 | 哪群員工       |
| You can reach us by phone.             | You may contact the office by telephone. | 不是唯一聯絡方式   |
| We will cover your travel costs.       | Travel expenses will be paid for.        | 是否包含餐宿     |
| Access is restricted to staff.         | Only employees may enter.                | 是否另有例外     |
| The service will resume on Monday.     | The service will restart on Monday.      | 週一之前可能停用   |
| The proposal is still under review.    | A decision has not yet been finalized.   | 尚未核准，不等於否決 |

## 限定詞比冷僻單字更容易決定答案

| 表達                       | 要讀出的範圍         | 常見誤讀        |
| ------------------------ | -------------- | ----------- |
| only                     | 僅限             | 把其中一種優惠擴成全部 |
| except / excluding       | 排除             | 忘記例外        |
| unless                   | 除非；若不          | 忽略條件而選必然發生  |
| at least                 | 至少，含該數字        | 看成超過、不含     |
| no more than             | 不超過，含上限        | 看成至少        |
| subject to approval      | 仍須核准           | 以為已批准       |
| no later than            | 最晚於            | 看成那天以後      |
| as of                    | 自某時間起／截至某時，依語境 | 與截止提交混淆     |
| provided that            | 只要符合該條件        | 看成無條件承諾     |
| instead of / rather than | 改為前者、不是後者      | 把舊方案當最終方案   |

## 兩題原創自測

1. “The discount applies to room rental only.” 哪個敘述有依據？  
   (A) 餐費也打折　(B) 場地租金享折扣　(C) 所有服務免費　(D) 折扣已取消
2. “Requests are subject to approval.” 哪個敘述有依據？  
   (A) 所有申請已核准　(B) 申請都被拒絕　(C) 仍需要核准　(D) 不可提出申請

> [!success]- 解答與解析
> 1. **B**：only 限定 room rental；A、C 擴大範圍，D 沒有依據。
> 2. **C**：需要核准是條件；A、B 都把未定結果當已定，D 也未被陳述。
